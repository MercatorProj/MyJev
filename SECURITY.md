# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues.

Open a private GitHub security advisory at <https://github.com/MercatorProj/MyJev/security/advisories/new>. If that page is unavailable, contact the maintainer through the GitHub profile at <https://github.com/MercatorProj>.

Please include reproduction steps, affected versions, backend, and any logs with credentials removed. The maintainer will acknowledge reports and coordinate a fix and disclosure.
